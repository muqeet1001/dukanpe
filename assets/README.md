# Brand assets in the interface

The app is branded Dukanpe, with a navy/cyan text wordmark and an original D app icon (`dukanpe-icon.svg`, exported to `icon.png` and `favicon.png`). Its four tabs and merchant flows use Paytm's app as a visual reference.

| Asset | Public source |
|---|---|
| paytm-logo.svg and paytm-logo.png | [Paytm website header wordmark](https://pwebassets.paytm.com/commonwebassets/paytmweb/header/images/logo_new.svg) |
| phonepe.png | [PhonePe official Google Play listing](https://play.google.com/store/apps/details?id=com.phonepe.app) |
| gpay.png | [Google Pay official Google Play listing](https://play.google.com/store/apps/details?id=com.google.android.apps.nbu.paisa.user) |
| whatsapp.png | [WhatsApp official Google Play listing](https://play.google.com/store/apps/details?id=com.whatsapp) |

The Paytm SVG and PNG are retained as design reference assets; the live header displays Dukanpe. Source-app brand icons are loaded from the publisher-provided Play listing assets and bundled so the interface does not depend on a remote image request.

The visual layout reference is the first published screenshot in [Paytm's app listing](https://play.google.com/store/apps/details?id=net.one97.paytm), inspected on 17 October 2026. The reference's consumer payment actions are adapted to this product's merchant actions; its screenshot is not used as the app interface.
